# 新奥游戏完整界面规格 V1

本文件把现有游戏规则、已生成的 2.5D 设计图和参考图整理成可实现的界面合同。参考图只用于视觉方向；页面必须继续使用新奥游戏自己的资源、名称和规则。

## 0. 统一风格基线（唯一有效）

此前的概念图存在“青蓝线框 HUD”和“高亮电影感面板”两种倾向。本版收敛为一套风格，后续新图和前端实现均以 [ui-style-guide-v1.svg](ui-style-guide-v1.svg) 为准：

- **背景**：`#020617` 深空黑蓝；场景使用低对比星尘和行星体积光。
- **主光**：青色 `#38EAFF`，用于交互、护盾、选中态、路径和进度。
- **空间层**：紫色 `#7C75FF`，只用于星系地图、研究节点和空间深度。
- **决策色**：琥珀 `#FFD05A`，只用于主 CTA、确认和可执行警告。
- **危险色**：红色 `#EF4E62`，只用于真实损失、攻击、受损和不可逆操作。
- **面板**：深色半透明玻璃、单像素青色边缘、统一切角；不使用彩虹渐变、厚重金色边框或随机霓虹。
- **层级**：中央场景约 70%，顶部资源约 10%，左右信息约 15%，底部导航约 5%。
- **字体**：中文使用清晰无衬线，英文使用窄体大写；关键数字使用等宽字形；避免过细和过小的字重。
- **光照**：统一左上冷色轮廓光，建筑/舰船接触面有柔和阴影；发光只围绕交互或能量源。

### 规划顺序（先统一，再细节）

1. **视觉锁定**：先使用 `ao-xin-ui/ui-style-guide-v1.svg` 和 `ao-xin-ui/ui-control-bars-v1.svg` 锁定颜色、面板、顶部资源栏、底部导航、图标和间距。
2. **页面壳锁定**：所有页面先套同一个 `GameShell`（TopResourceDock + SceneViewport + SidePanel + BottomModuleNav）。页面只允许替换场景和右侧详情内容。
3. **交互锁定**：每页只保留一个琥珀色主 CTA；抽屉、弹窗、队列、错误和确认状态使用同一套组件。
4. **内容细化**：最后才补建筑、舰船、防御、星球、防护罩、战报、研究节点和任务文案。
5. **响应式验收**：桌面和移动端只改变布局，不改变颜色语义、导航顺序或操作名称。

以下组件 ID 为全局唯一合同：`TopResourceDock`、`SceneViewport`、`LeftStatusPanel`、`RightDetailPanel`、`BottomModuleNav`、`DrawerSheet`、`PrimaryAction`、`StatusChip`、`QueueRow`、`RiskMeter`、`ShieldState`。

## 1. 全局界面壳

### 桌面布局（1440×900）

- 顶部资源 Dock：金属、晶体、燃料、能源、人口/舰队容量、研究点、护盾完整度、星历时间。
- 中央场景：占据视觉主面积，显示星球、船坞、研究网络或星系地图；可缩放、拖拽，点击对象后更新右侧详情。
- 左侧状态栏：当前星球/区域状态、扫描、队列、过滤器和风险摘要。
- 右侧详情栏：选中对象、属性、前置条件、资源消耗和一个主操作按钮。
- 底部导航：基地、研究、防御、星系、舰队、战报；低频页面收进“更多”。

### 移动布局（390×844）

- 顶部资源 Dock 变为横向滚动，默认只展示金属、晶体、燃料、护盾四项。
- 左右面板改为底部抽屉；一次只展开一个抽屉，关闭后场景保持可见。
- 底部固定 5 个入口：总览、星系、舰队、战报、更多。
- 所有主操作最小 44×44 CSS 像素；风险、护盾、结果必须同时有颜色和文字。

## 2. 页面清单与细节

### P01 星球总览 / Colony Overview

- 场景：带稳定/受压/受损状态的防护罩星球，建筑以 2.5D 分层平台显示。
- 左栏：星球名称、坐标、人口、电力产出/使用、建筑数量、防御等级、大气扫描。
- 右栏：选中建筑（等级、完整度、功能、升级成本、预计完成时间）。
- 场景交互：点击建筑显示热点；点击护盾显示完整度、剩余容量和最近威胁。
- 主 CTA：升级建筑；次 CTA：查看详细报告。
- 空态：无殖民地时显示“选择殖民地”与“开始殖民”两个动作。

### P02 建筑 / Buildings

- 中央：可旋转的 2.5D 建筑岛，支持按生产、能源、居住、防御筛选。
- 左栏：建筑分类、已用空间/总空间、当前建造队列。
- 右栏：建筑属性、每小时产出、前置科技、升级后变化。
- 状态：可建造、资源不足、前置不足、队列已满、施工中、暂停。
- 主 CTA：建造/升级；危险 CTA：拆除，必须二次确认并显示退款规则。

### P03 轨道船坞 / Shipyard

- 场景：轨道船坞、停泊舰船、吊臂和发光建造平台。
- 左栏：船坞完整度、泊位容量、当前建造、完整队列。
- 右栏：战舰蓝图、定位、船体、护盾、火力、货舱、乘员、建造成本。
- 状态：可建造、燃料不足、资源不足、泊位不足、维护中。
- 主 CTA：建造舰船；次 CTA：加入队列、暂停、调整顺序。

### P04 舰队 / Fleet

- 场景：舰队编队 3D 预览与编组槽位。
- 左栏：舰队列表、所在位置、任务状态、返航 ETA。
- 右栏：选中舰船数量、船体伤势、护盾、货舱、燃料、可执行任务。
- 状态：待命、运输中、侦察中、战斗中、受损、维修中、失联。
- 主 CTA：派遣；次 CTA：召回、改名、拆分编队。

### P05 星系导航 / Galaxy

- 场景：可缩放星系、星球节点、航线和残骸场；军事情报只显示已侦察内容。
- 左栏：扇区坐标、附近天体、所有权过滤器、路线分析。
- 右栏：目标星球概况、防护罩状态、可见情报深度、预计风险。
- 状态：安全、注意、高风险、不可达、情报过期。
- 主 CTA：选择目的地；次 CTA：扫描、查看航线、加入收藏。

### P06 舰队派遣 / Dispatch Wizard

- Step 1 目标：选择起点、目的地、任务类型（运输/部署/殖民/侦察/攻击/回收）。
- Step 2 编队：选择舰船数量，显示货舱、燃料和护航缺口。
- Step 3 航线：显示安全/注意/高风险分段、距离、ETA、燃料保留线。
- Step 4 确认：冻结资源、显示撤回规则、预计收益和失败恢复路径。
- 主 CTA：确认派遣；若请求过期，必须回到确认页刷新状态，禁止自动提高预算重发。

### P07 研究网络 / Research

- 场景：研究核心与 8 个以上科技节点，节点以连线表示前置关系。
- 左栏：能源、防御、推进、资源、电子与 AI、生物科技分类及完成度。
- 右栏：科技等级、效果变化、前置条件、研究耗时和研究队列。
- 状态：已完成、研究中、可研究、锁定、前置不足。
- 主 CTA：开始研究；次 CTA：加入队列、取消研究。

### P08 防御网 / Defense Grid

- 场景：带防护罩的行星防御设施，显示覆盖半径、能量连线和敌方威胁方向。
- 左栏：护盾完整度、防御覆盖率、能量消耗、警报、施工队列。
- 右栏：轨道炮、护盾发生器、拦截井、雷达阵列、点防御炮的属性与升级成本。
- 状态：稳定、受压、受损、供能不足、覆盖缺口。
- 主 CTA：升级防御；次 CTA：调整阵列、查看威胁预测。

### P09 战报 / Battle Reports

- 场景：战斗残骸、受损舰船和受压护盾，动画可跳过直接读结果。
- 左栏：战报列表，显示胜利/失败/防守成功、时间、对手和未读标记。
- 右栏：结果、双方损失、残骸、经验、逐轮时间线、撤退阈值。
- 必须显示：掠夺权是否成立、撤退是否生效、固定防御是否继续参战。
- 主 CTA：查看回放；次 CTA：进入恢复、回收残骸、再次派遣。

### P10 舰队恢复 / Recovery

- 场景：维修平台、受损舰船、残骸分配和维修进度。
- 左栏：维修队列、受损比例、预计完成时间、材料需求。
- 右栏：船体份额、残骸份额、保障份额、可领取上限和互斥权益提示。
- 状态：可修理、材料不足、保障待领取、已领取、权益已过期。
- 主 CTA：修复舰队；次 CTA：领取残骸、领取保障、使用安全救援运输艇。

### P11 任务与事件 / Missions

- 场景：任务节点、通讯条和当前事件背景，不阻断主场景操作。
- 左栏：进行中、可接取、已完成、失败待恢复。
- 右栏：任务目标、合法区域、触发时间、可选行动、失败恢复和关闭条件。
- 主 CTA：接受/继续；危险任务必须展示资源预算与撤退选项。

### P12 经济与物流 / Logistics

- 场景：资源流向图、仓库、公共站和前哨之间的运输线。
- 左栏：库存、产能、仓储上限、滚动支出预算。
- 右栏：运输合同、报价有效期、NPC 库存来源、装载/卸货状态。
- 状态：报价有效、报价过期、满仓、缺燃料、授权冲突、请求进行中。
- 主 CTA：确认运输；次 CTA：取消、减载、换路线。

### P13 成就与军官 / Progression

- 场景：文明里程碑、军官头像和被动加成。
- 左栏：成就类别、完成度、未领取奖励。
- 右栏：军官技能、等级、适用场景、授权到期时间。
- 主 CTA：领取、任命、续期；不允许用不可执行建议替代明确原因。

### P14 图鉴与设置 / Codex & Settings

- 图鉴：建筑、科技、舰船、防御、星球和状态图标，支持搜索与筛选。
- 设置：音效、动画、色盲辅助、减少动画、文字大小、语言、存档导入/导出。
- 危险操作：重置本地存档、放弃殖民地、退出授权必须二次确认。

## 3. 通用状态与反馈

| 状态 | 视觉 | 文案要求 |
|---|---|---|
| 成功 | `ok` 绿色 + 勾选 | 明确结果与下一步 |
| 警告 | `warn` 琥珀 + 三角 | 写明风险、时间和可采取动作 |
| 危险 | `bad` 红色 + 警报 | 仅真实损失、攻击和不可逆操作使用 |
| 进行中 | 青色进度条 | 显示剩余时间和可取消性 |
| 空状态 | 场景图标 + CTA | 不使用裸“暂无数据” |
| 请求过期 | 重新验证横幅 | 回到确认页，不自动重发 |

所有数字使用等宽 `.num`；关键正文使用 `text-ink-2` 以上；弹窗必须有 `role=dialog`、焦点管理、Esc 关闭和还焦。

## 4. 资源与物料映射

- 战舰：侦察舰、运输舰、护卫舰、工程舰、科研舰、殖民舰、回收舰。
- 防御：轨道炮、护盾发生器、拦截井、雷达阵列、点防御炮。

- HUD：金属、晶体、燃料、能源、人口、研究、航线、目的地、风险、护盾、残骸、维修、保险。

## 5. 验收标准

1. 每个页面都有一个明确的主决策，不超过一个主 CTA。
2. 玩家能在 3 秒内看到资源、护盾、当前任务和下一步动作。
3. 桌面中央场景始终可见；移动端面板以抽屉覆盖，不永久遮挡场景。
4. 风险、损失、撤退、恢复权益都在确认前显示，不能只藏在战报里。
5. 断网、重复点击、过期请求、资源不足、满仓和授权冲突都有可读反馈。
6. 1440×900 与 390×844 均通过键盘顺序、触控尺寸、减少动画和文字放大检查。
