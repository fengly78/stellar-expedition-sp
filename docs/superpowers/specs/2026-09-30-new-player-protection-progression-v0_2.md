# Stellar Expedition 新手保护与成长里程碑 v0.2

> 状态：Candidate  
> 日期：2026-09-30

## 1. 目标

避免传统长线战争游戏常见问题：

- 新玩家在理解系统前被掠夺；
- 保护期结束瞬间成为资源包；
- 老玩家通过低风险刷新人获利；
- 玩家主动攻击后又退回绝对保护；
- 单纯按账号年龄无法反映真实实力。

## 2. 保护状态

### P0 Tutorial
账号初始状态。

- 完全免受玩家攻击；
- 可打教程 PvE；
- 不允许向外主动 PvP；
- 市场额度有限。

退出条件：
- 完成核心教程；
- 或账号满 24h。

### P1 Protected
主要新手阶段。

基础持续到 72h，并同时参考成长分。

- 不能被远高于自身实力玩家攻击；
- 可以攻击同保护层玩家；
- 主动攻击普通玩家后进入 Aggressor Window。

### P2 Transitional
保护过渡期。

- 可被更广范围目标攻击；
- 保留资源保护仓；
- 连续被攻击收益快速衰减；
- 来袭预警提供最低保证。

### P3 Open
正常宇宙规则。

仍受反骚扰与实力差距收益衰减约束。

## 3. Growth Score

不要只用总资源积分。

候选：

```text
growth_score =
  0.35 × economy_value
+ 0.20 × research_value
+ 0.30 × military_value
+ 0.15 × colony_value
```

所有项先归一化。

攻击允许与否、收益衰减不能只依赖该分数，还需要：
- attacker/defender ratio；
- 最近 7 天 PvP；
- 目标是否主动进入战争；
- 联盟战争状态。

## 4. 实力差保护

候选规则：

- P1：攻击者 growth_score 不得超过目标 3×。
- P2：不得超过 5×，但主动战争状态可放宽。
- P3：不硬禁止，但超过 10× 时掠夺收益大幅衰减。

这些值必须通过实际人口分布模拟。

## 5. 主动攻击窗口

P1/P2 玩家若主动攻击 Open 玩家：

- 进入 24h Aggressor Window；
- 对该目标及其协防参与者降低保护；
- UI 必须在出发前明确提示；
- 召回不能取消窗口。

防止“受保护玩家无风险骚扰”。

## 6. 连续攻击衰减

同一 attacker 对同一 defender 在 24 小时内：

- 第 1 次：100% 合法掠夺率
- 第 2 次：70%
- 第 3 次：40%
- 第 4 次：20%
- 第 5 次及以后：10%

是否进一步硬限制攻击次数取决于测试。

联盟轮流攻击同一新手需要额外群体滥用检测。

## 7. 安全库存

保护仓不是额外资源，而是“不可掠夺比例”。

候选：
- P1：至少保护库存的 70%
- P2：至少 45%
- P3：基础 20%，可由地下掩体提高

安全库存上限也需要与星球经济规模关联，避免巨量囤积。

## 8. 战败恢复

玩家在 24h 内遭受重大损失：

条件候选：
- 军事资产损失 >50%
- 或总资产损失 >25%

可获得 Recovery 状态：

- 建筑不受攻击加成；
- 资源生产 +10%～15%
- 防御修复加速
- 不能增加进攻火力
- 24–48h 后结束

避免把恢复 buff 变成复仇攻击优势。

## 9. 里程碑

### Milestone A — First Industry
- 金属矿 L2
- 晶体矿 L1
- 太阳能 L2

### B — Research Online
- 机器人 L1
- 实验室 L1
- 第一项科技

### C — First Fleet
- 船坞 L1
- 侦察探针
- 第一次星系扫描

### D — First PvE
- 第一支战斗舰队
- 击败基础海盗

### E — Stable Colony
- 稳定能源
- 仓储
- 基础运输
- 天体物理

### F — Expansion
- 第一艘殖民舰
- 第二星球

保护状态变化与这些里程碑一起判断，而不是只看时间。

## 10. 回归保护

离线 14 天以上且军事资产显著落后于服务器中位数的玩家，可获得短期 Return Shield：

- 24–48h；
- 不能主动 PvP；
- 可整理经济与撤离舰队；
- 有明确冷却，防反复利用。

## 11. UI

所有保护状态必须显示：

- 当前层级；
- 剩余时间；
- 哪些行为会失去保护；
- 可攻击范围；
- 安全库存；
- 最近攻击衰减。

不允许隐藏规则。

## 12. 验收指标

- 新账号前 24h 被玩家摧毁率接近 0。
- P1 → P2 转换后 24h 流失率无明显尖峰。
- 高分玩家攻击新人不是高收益活动。
- 新手主动 PvP 不可无代价利用保护。
- 保护机制不成为长期安全囤积工具。

## 13. RC2 收尾裁决：Power Score 与状态转换

此前依赖“归一化 growth_score”的候选方案不再用于 MVP，因为它会随服务器人口分布变化，难以审计。

MVP 使用固定 Power Score：

```text
P =
  E
  + R
  + 1.25 × max(M_current, 0.5 × M_peak_7d)
  + 100000 × max(0, planet_count - 1)
```

其中：

- E：已完成建筑累计投入的 V；
- R：已完成科技累计投入的 V；
- M_current：当前舰船 + 防御 V；
- M_peak_7d：过去 7 天军事资产峰值。

7 日军事峰值下限用于防止玩家故意自毁/转移舰队后降分刷新人。

状态机：

- P0 → P1：完成核心教程 **或** 账号达到 24h；
- P1 → P2：账号达到 72h **且** 核心里程碑完成；
- P2 → P3：账号达到 120h 且 P >= Open Threshold；
- 主动攻击产生 24h Aggressor Window，召回不取消。

联盟宣战不能绕过 P0/P1。P2 玩家只有明确加入战争后才按战争规则处理。

最终参数以 `balance_rc2_candidate.json` 为准。
