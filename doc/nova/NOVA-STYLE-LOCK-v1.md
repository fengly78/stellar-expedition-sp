# NOVA ORBITALS 统一视觉规范 v1

## 目标

所有游戏界面、建筑、战舰、防御设施、星球和制造组件使用同一套 NOVA ORBITALS 视觉语言。素材先统一轮廓、材质和发光规则，再做单项细节。

## 视觉基准

- 视角：轻俯视 2.5D，保留真实体积、投影和分层结构。
- 背景：深蓝黑星空，低密度星尘和轨道网格，不抢主体。
- 主色：深海军蓝底、青蓝发光边缘、白蓝高光。
- 状态色：橙色只用于警报、敌对、缺料和危险状态；绿色只用于完成与在线。
- 材质：拉丝枪灰金属、陶瓷装甲、透明能量玻璃、少量橙色热源。
- 发光：边缘发光和核心能源发光分开，避免整件物体泛蓝。
- 轮廓：每个建筑、舰艇、防御设施必须拥有独立剪影和功能识别点。

## 界面框架

- 顶部：资源条、时间、信号、设置和玩家信息。
- 中央：星球、轨道船坞或星系地图，保持主要视野清晰。
- 左侧：总览、队列、威胁与状态。
- 右侧：当前选中对象的详情、属性、消耗与操作。
- 底部：基地、科研、防御、舰队、报告、更多；固定使用同一套图标和发光选中态。
- 面板：深蓝半透明玻璃，青蓝 1px 边框，角部切角，标题为中文主标题 + 英文副标题。

## 素材分类

1. 星球与护盾：采用紧贴星球表面的完整球形护盾；护盾使用细密六边形能量网格、明亮青蓝边缘和顶部环形发射器。稳定态为纯青蓝，过载态加入少量橙色裂纹与高亮单元，受损态可出现局部缺失单元，但外轮廓仍保持完整球形。
2. 建筑：指挥中继、轨道电梯、聚变反应堆、栖息穹顶、雷达阵列。
3. 战舰：侦察艇、护卫舰、驱逐舰、巡洋舰、战列舰。
4. 防御：轨道炮塔、拦截井、点防炮、护盾发生器、导弹阵列。
5. 制造组件：舰体骨架、引擎、武器舱、护盾环、资源罐。

## 生成约束

- 不使用扁平图标、卡通比例、奇幻装饰和过量紫色。
- 不新增外交、角色、剧情等扩展系统，先完成主框架素材。
- 新图必须以本目录中的 `nova-orbitals-manufacturing-thread-workspace.png` 为风格参考。
