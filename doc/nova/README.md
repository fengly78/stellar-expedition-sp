# NOVA ORBITALS 风格目录

这里存放奥新游戏采用的 NOVA ORBITALS 统一风格参考图、核心素材图和物料设计图。

统一规范见 [NOVA-STYLE-LOCK-v1.md](./NOVA-STYLE-LOCK-v1.md)。后续建筑、舰艇、防御和界面素材都以该规范为准。

- `nova-orbitals-manufacturing-thread-workspace.png`：制造多线程工作台参考图。
- `asset-design-sheet-v2-shielded-2.5d.png`：护盾星球与 2.5D 建筑资产板。
- `materials-design-sheet-v1.png`：建筑、舰艇、防御与资源物料设计板。
- `nova-asset-atlas-v1.png`：统一素材总图，包含星球护盾、建筑、战舰、防御设施和制造组件。
- `nova-buildings-atlas-v1.png`：完整建筑 2.5D 外观图，覆盖资源、能源、生产、科研、船坞和仓储。
- `nova-ships-atlas-v1.png`：完整舰艇 2.5D 外观图，补入殖民舰、探测器和死星级 Planetbreaker。
- `nova-defense-atlas-v1.png`：完整防御设施 2.5D 外观图，覆盖炮台、护盾、反导和星际导弹。
- `nova-home-planet-overview-pc-v1.png`：按 NOVA 制造工作台风格生成的主星球 PC 总览界面，包含全包裹护盾、建筑热点、建设队列、选中建筑详情和星球拖动/缩放控制。
- `nova-galaxy-map-pc-v2-shield-standard.png`：按新版护盾标准重做的星系查看 PC 界面，包含紧贴球面的六边形护盾、顶部环形发射器、可拖动/缩放星系、轨道航线、目标星球详情、扫描和派遣舰队操作。
- `nova-galaxy-atlas-switcher-pc-v1.png`：多星系切换界面，包含星系列表、已探索/收藏/可前往筛选、星系群导航、旅行信息和进入星系操作。
- `nova-galaxy-atlas-switcher-pc-v2-colony-switcher.png`：加入左下角殖民地切换器，可快速切换主星球与其他基地，并显示坐标和护盾完整度。
- `nova-construction-pc-v2-unified.png`：按原始制造工作台外壳重做的建设模块，体现单行星一个执行中建筑任务、最多三条待执行队列、升级预览和本地资源扣费。
- `nova-research-pc-v2-unified.png`：按原始制造工作台外壳重做的研发模块，体现文明共享研究队列、科技依赖网络、等级效果和研究成本。
- `nova-manufacturing-pc-v2-unified.png`：按原始制造工作台外壳重做的制造模块，保留三线程制造、蓝图依赖、批次交付、物料配送和质量检测。
- `nova-fleet-command-pc-v1.png`：舰队模块，体现五类 MVP 舰船、运输/部署/殖民/侦察/攻击任务、燃料消耗、货舱和召回。
- `nova-planet-shield-spec-v1.png`：行星护盾细节规范，锁定紧贴星球的六边形球形护盾、顶部环形发射器以及稳定/过载/受损三种状态。

参考图特征：顶部资源 Dock、左侧多线程队列、中央 2.5D 场景、右侧对象详情、底部模块导航和青蓝玻璃 HUD。
