## 三、缺口一：设计稿有、实现没有的**装饰性面板**

这些在设计稿里占据显著位置，但实现里完全没有。它们**不影响可玩性**，
属于「锦上添花」，但会让懂设计的玩家一眼看出与稿不符。

### 3.1 总览页「星球概览」缺 3 项

设计稿左栏四个指标：护盾完整度 / 人口总量 / 电力输出 / **建筑数量 8/12** + **大气扫描 宜居**。

实现（`Overview.tsx` 星球概览）有：护盾穹顶、基地容量、电力输出、设施种类、防御设施。
缺：
- **人口总量**（POPULATION 12,480,000）——代码里完全没有人口概念
- **大气扫描 / 宜居度**（ATMOSPHERIC SCAN）——只有 `temperatureMax`，无宜居判定

注：建筑的「结构完整度 INTEGRITY 99.8%」在上一轮已作为假数据清除，
这是**正确的**（代码无法推导），不要恢复。

### 3.2 选中建筑详情缺 4 行

设计稿右侧「选中建筑」有 5 行属性：结构完整度 / 指挥范围 / 资源生产加成 / 舰队容量 / （建造时间）。
实现（`Overview.tsx` 的 `selectedStats`）按建筑类型给的是**实算值**：
金属矿→金属产量、实验室→研究上限、船坞→活跃舰船数、传感器→扫描覆盖。

这个差异是**有意为之且正确**——设计稿的「结构完整度 99.8%」是编造的，
实现换成可从状态推导的真实指标。**但建筑升级页面（`Buildings.tsx`）
确实缺了设计稿里的「生产效果 PRODUCTION EFFECT」区块**（金属/晶体/氘产量/能源产出的 +N/h）。

### 3.3 制造页缺 3 个底部面板

设计稿中列下方有：**生产调度器**（三线程甘特条）、**原料运输**（在途货物 ETA）、
**质量检测**（结构完整度/武器校准/护盾强度/A 系统检测四项百分比）。

实现（`Shipyard.tsx`）**完全没有**这三个面板。
这类数据需要模拟物流/质检状态机，属于新增机制而非纯装饰。

### 3.4 制造页缺「蓝图依赖关系图」

设计稿中央是**舰体结构/推进引擎/武器系统/护盾模块 → 战列巡航舰**的依赖网络，
带「已满足/进行中/未满足」三色图例和「冲突提示」。

实现（`Shipyard.tsx`）只有**文字列表**形式的「所需材料 / 解锁需求」，
无图形化依赖网络。研发页有科技树连线，制造页没有对应物。

## 四、缺口二：设计稿有、代码里完全没有的**资源与机制**

### 4.1 暗物质（DARK MATTER）—— 最重要的一处

设计稿**每一张**顶部资源条都有第四项：暗物质 42,880 +120/h。
代码里 `darkMatter` 命中数为 **0**——这个资源完全不存在。

背景：暗物质是原版 OGame 的付费货币，上游 ogame-opensource 把所有 Premium
功能（暗物质、军官、贸易商）都免费开放。本项目已实现了**军官**
（`Officers.tsx`），但**暗物质没有对应替代品**。

这是个**产品决策**，不是 bug。要么补一个暗物质资源及消费场景，
要么在设计稿层面明确「本项目不做暗物质」并从设计稿中移除。
**不能留着设计稿有、代码没有、也不说明的状态。**

### 4.2 舰队模块设计稿缺失

如第一节所述，`nova-fleet-command-pc-v1.png` 不存在。
舰队页现有实现（`Fleet.tsx`）只有任务列表 + 舰队编成 + 货舱 + 页脚状态。

对照 README 描述的「五类 MVP 舰船、运输/部署/殖民/侦察/攻击任务、
燃料消耗、货舱和召回」逐项核实：

| README 描述 | 实现状态 |
|---|---|
| 五类 MVP 舰船 | ✓ `SHIP_ORDER` 15 种，五类任务齐备 |
| 运输/部署/殖民/侦察/攻击 | ✓ `TYPE_KEY` 全有 |
| 燃料消耗 | ✓ `DispatchWizard` 用 `fleetFuel`/`flightTime` 实算并显示 |
| 货舱 | ✓ `fleet.missionCargo` |
| **召回** | ✗ 无实现——任务进行中无法中途召回 |

## 五、优先级建议

| 优先级 | 项 | 理由 |
|---|---|---|
| P1 | 暗物质：补实现或从设计稿移除 | 设计稿与代码直接矛盾，且每张稿都有 |
| P1 | 补舰队模块设计稿 | 唯一的模块级缺口，且该页刚修过 P1 |
| P2 | 舰队页补「召回」（任务中途返航） | 燃料/货舱已实算，召回是唯一缺的交互 |
| P2 | 建设页补「生产效果」区块 | 设计稿有，实现缺，数据可实算（不像完整度是编造的） |
| P2 | 制造页补「蓝图依赖关系图」 | 研发页有树、制造页无，可复用科技树组件 |
| P3 | 总览页补大气扫描/宜居度 | 纯新增指标，需要先定义规则 |
| P3 | 人口总量 | 纯新增概念 |
| P3 | 制造页三个底部面板 | 需要新状态机，工作量最大 |
| — | 结构完整度 99.8% 等 | **不要恢复**，是编造数据，上一轮已正确清除 |
