# OGame 经济系统体检与调优提案

- **日期**：2026-09-18
- **数据来源**：对 `web/src/game/objects.ts`、`npc.ts`、`state.ts` 的实际公式做数值脚本测算（`.econ-analysis.mjs`）
- **前提**：所有数值均为单机离线模拟结果，**未经真人 playtest**。改数值前请先看「如何验证」一栏

---

## 0. 先把游戏的核心说清楚

反推自代码（**请确认是否符合你的设计意图**）：

**Fun Hypothesis**：在一条不停向前推进的时间轴上，用有限的建筑空间和有限的航线数，把资源换成产能、把产能换成舰队，再从星系里兑现回来。

**Design Pillars（反推）**

| # | Pillar | 代码里支撑它的机制 |
|---|---|---|
| 1 | **时间不可再生**：挂机也在推进，决策要趁早 | tick 按真实时间推进，离线补偿 12h 上限 |
| 2 | **广度优于深度**：开殖民地比死磕单星聪明 | 殖民地数 = 3 + 计算机技术（上限 7）；单星 maxFields 200 |
| 3 | **出兵必有代价**：不可逆损失创造真实张力 | 战斗损失、战损船不返还、残骸才回收一部分 |
| 4 | **进度清晰可见**：数字必须对得上 | 产量/电力/倒计时 UI（本次修的就是这一条） |

本次所有建议都对齐这四条。Pillar 4 在本次修复前是**崩的**（UI 数字和实际到账不一致），现在补上了。

## 1. Sources & Sinks 全景

### Sources（资源从哪来）

| 来源 | 量级 | 性质 |
|---|---|---|
| 矿产（母星 + 最多 6 个殖民地） | 单星金属矿 Lv.20 ≈ 26.9k/时，Lv.30 ≈ 104.7k/时 | **长期主引擎** |
| NPC 掠夺（存量） | 难度2 目标平均 ≈ 131k 金属（一次性） | 开罐，短期爆发 |
| NPC 资源再生 | 难度 0/1/2 = 200/500/800 金属每小时 | **持续速率瓶颈** |
| 战役奖励 | 8 关累计 ≈ 427k 金属当量 | 一次性 |
| 教程 / 每日 / 残骸回收 / 远征 | 中小 | 补充 |

### Sinks（资源到哪去）

| 去处 | 量级 | 备注 |
|---|---|---|
| 建筑升级 | 60×1.5^L（金属矿），指数增长 | **主导 sink** |
| 造船 / 防御 | 数千～数千万 | 战斗损失会成倍放大 |
| **战斗损失** | 不可预测，一次会战可吃掉数百万 | 最大隐性 sink，也是 Pillar 3 的执行者 |
| 军官周薪 | 数千/周 | 小额但持续 |
| 舰队燃料 | Ceil(count×fuel×dist/35000) | 重氢的小口 sink |
| 仓储溢出 | 超过 `10000×2^L` 即丢弃 | 隐式销毁口 |

**通胀判定**：建筑成本按 1.5^L～2^L 增长，显著快于产量 ~1.1^L·L，因此**不会出现资源无限堆积的恶性通胀**，而是表现为"后期升级越来越慢"。这是健康的（也是 OGame 的原设计）。真正的风险在下一条。

## 2. 三个确凿的数据发现

### 发现 1（严重）：能源系统从来没有生效过

`solarOutput` 乘了 `SPEED`（=4），`energyConsumption` 没乘：

```ts
solarOutput(L)      = 20 × L×1.1^L × SPEED      // 乘了
energyConsumption(L)= 10 × L×1.1^L              // 没乘
```

实测供需比：

| 三矿同级 | 总耗电 | 同级太阳能电站发电 | 供需比 | 实际 eta |
|---|---|---|---|---|
| Lv.10 | 1,037 | 2,075 | **2.00** | 1.00（截断） |
| Lv.20 | 5,382 | 10,764 | **2.00** | 1.00（截断） |
| Lv.30 | 20,939 | 41,879 | **2.00** | 1.00（截断） |
| Lv.40 | 72,415 | 144,830 | **2.00** | 1.00（截断） |

`withEnergyDeficit` 里 `ratio > 1 → 1`，所以**无论玩家怎么瞎建，产量永远是满值**。UI 上那个「⚡ 输出/消耗」指示器一直在说谎。

这不是调优问题，是**公式不一致的 bug**。旁证：`satelliteEnergy` 同样乘了 SPEED——太阳能卫星存在的意义就是"用电厂发电不够时补电"，这条路现在是死的，说明设计意图确实是三者都要乘 SPEED。

**修复**：给 `energyConsumption` 补上 `* SPEED`。修复后三个同级矿配同级电站的 ratio = 0.50，玩家需要把电站多建约 7 级才够用——**电力重新变成日常决策**。

> ⚠️ **这个修复有副作用，我没有擅自改**：所有现有存档会立即出现电力缺口，最坏情况产量腰斩（ratio 0.5）。要么配合一次公告式的存档迁移，要么只在新建档生效。**请你拍板。**

**验证路径**：新建档游玩，记录玩家处于「电力不足」状态的时间占比。目标区间 **20%–40%**——低于 20% 说明电还是太富裕，高于 40% 说明太烦人。

### 发现 2：深挖矿产在 Lv.20 之后边际回报崩塌

把矿从 L−1 升到 L 的成本，除以它带来的每小时增量产出：

| 等级 | 升级成本 | 时产增量 | 回本 | |
|---|---|---|---|---|
| 5 | 304 | 439 | **0.7h** | |
| 10 | 2,307 | 943 | **2.4h** | |
| 15 | 17,516 | 1,899 | **9.2h** | |
| 20 | 133,010 | 3,670 | **36h** | 1.5 天 |
| 25 | 1,010,047 | 6,895 | **146h** | 6.1 天 |
| 30 | 7,670,042 | 12,690 | **604h** | **25 天** |
| 35 | 58,244,384 | 22,993 | **2,533h** | 105 天 |
| 40 | 442,293,293 | 41,145 | **10,750h** | 448 天 |

根因：成本 `1.5^L` 相对产量 `L×1.1^L` 的比值 ≈ `1.36^L / L`，指数发散。

这件事本身**不必然是坏事**——它恰好制造了 Pillar 2「广度优于深度」的压力。真正的问题是：**游戏没有把这条最优路径告诉玩家**。教程在第 1 步之后就撒手了，玩家会一路把母星矿挖到 Lv.25+，然后在第 6-10 天撞上"升级毫无感觉"的墙，然后流失。

敏感性参考（把金属矿 cost factor 调低的后果）：

| factor | Lv.30 回本 | Lv.40 回本 |
|---|---|---|
| 1.50（现状） | 604h | 10,750h |
| 1.45 | ≈226h | ≈2,700h |
| 1.40 | ≈82h | ≈640h |
| 1.35 | ≈28h | ≈140h |

**我的建议**：**先不动数值**。这条曲线正是压玩家去扩张的那根杠杆，动它等于拆了 Pillar 2。要做的是让玩家看得懂这条曲线：

1. 在中后期教程/日报里明确提示「下一步的产能跃迁来自新殖民地，而不是把单星矿再往下挖三级」；
2. 建筑面板在检测到「某矿超过 Lv.22 且殖民地数 < 上限」时给一句提示。

> [PLACEHOLDER] 若实测发现玩家仍然卡在深挖，再回头考虑 factor → 1.45。**验证信号**：playtest 中玩家殖民数达 3 的中位时间点 vs 单星最高矿等级。如果殖民数中位数停留在 1、同时母星金属矿 > Lv.25，说明提示无效，才动数值。

### 发现 3：掠夺的长期收益在中期以后失去意义

| 指标 | 数值 |
|---|---|
| 满级计算机技术： concurrently 5 条航线、全打难度2 | 上限 **4,000 金属/时** |
| 单星金属矿 Lv.20 | 26,910 金属/时 |
| 单星金属矿 Lv.30 | 104,696 金属/时 |

掠夺可持续收益 ≈ 单星 Lv.30 矿产的 **3.8%**。也就是说：出了中期，出击在经济上是亏的（还要付燃料、承担战损）。玩家一旦发现，整套舰队/战斗/军官/残骸系统会集体失去动机，游戏收窄成"挂机收菜"。

这与 Pillar 3「出兵必有代价」不冲突——代价该有，但**收益也必须在**。

**候选对策**（都标 [PLACEHOLDER]，需 playtest）：

| 方案 | 改动 | 预期效果 | 风险 |
|---|---|---|---|
| C1 提高再生速率 | 难度2 从 800/时 → 6,000–10,000/时 | 5 slots 达 30–50k/时，约等于半颗星的产能，战斗型玩法成立 | 可能让囤积过于轻松，需同步重估 `npcRegen` 的 cap |
| C2 抬高单次掠夺占比 | 提高 raidMult（当前疑似 0.5） | 单次爆发更爽，但再生不变 → 只改变节奏不改变长期速率 | 容易变成"打一枪换个地方"的单调循环 |
| C3 提高残骸/回收收益 | debris 比例上调 | 让"打完还能捡"成为额外收益来源 | 需要 209 回收船具备足够吸引力 |

推荐 **C1**，因为它直接修正"长期收益率"这个根，且不改变单次手感。

**验证路径**：记录两队假想玩家（farm-only vs raid-heavy）在 8 小时 session 后的资源净值。目标：raid-heavy 应达到 farm-only 的 **60%–90%**——低于 60% 说明掠夺仍然鸡肋，高于 100% 说明 farming 失去意义。

## 4. 这次已经改掉的东西（影响 Profile 2/4）

- 建筑前置现在会正确计入科技等级 → **地形改造器、跳跃门终于能建了**。这直接解开了「单星空间锁死 200」的中期天花板，是 Pillar 2 的关键阀门，之前它是关死的。
- 产量现在只有一个计算函数 `planetProduction()`，UI 数字与实际到账永久一致（Pillar 4 的地基）。
- 战斗回放不再串台，大规模战斗也不会再把舰队画到画布外面。

## 5. Playtest：先定义"坏掉长什么样"

开始 playtest 之前先把失败信号钉死，否则测完只会得到「感觉还行」：

| 信号 | 说明 |
|---|---|
| **信号 A（电力无感）** | 玩家全程没有因为缺电而调整建造计划 → 发现 1 没修好，或修了但幅度不够 |
| **信号 B（深挖陷阱）** | 玩家殖民数停在 1，母星金属矿却超过 Lv.25 → 引导失败，需要上数值手段 |
| **信号 C（战斗无用）** | 玩家在拥有 10+ 轻战之后，出击频率反而下降 → 掠夺收益需要上调 |
| **信号 D（资源溢出）** | 任何资源长期顶到仓储上限且没有对应支出计划 → 缺 sink |

任何一个信号亮起，对应的就是上面表格里的具体条目，不要靠"再调调"解决。
